> 定位：第一个从「在线扩展」下载的扩展（格式见 `docs/design/extension-download.md`）。顺带解决「装扮怎么得到、在哪穿」（商店的装扮货架 F 批次起一直藏着）。

## 1. 玩法一句话

花金币买盲盒 → 摇一摇拆开 → 抽到一个系列里的东西（装扮能穿，摆件放进展示柜）→ 重复的变成碎片 → 碎片可以换指定的那一个。每个系列有一个**隐藏款**，抽多了一定会出（保底）。

## 2. 抽到什么

| 种类 | 说明 | 怎么用 |
|---|---|---|
| **装扮** | 现有 13 件（围巾、草帽、墨镜……）+ 每个新系列再加几件，都是 emoji 挂在猪身上 | 「衣柜」里穿上 / 脱下，一个部位一件 |
| **摆件** | 小动物、小食物之类的收藏品，只是好看 | 进「展示柜」，按系列摆成一排，集齐有标记 |

## 3. 系列（第一批 3 个，以后发新系列只要更新扩展）

| 系列 | 内容 | 隐藏款 |
|---|---|---|
| 🌾 农场好朋友（摆件） | 🐔 小鸡、🐄 奶牛、🐑 绵羊、🦆 鸭子、🐇 兔子、🐕 小狗 | ✨🐷 金猪 |
| 👒 春日衣橱（装扮） | 现有的草帽、樱桃发夹、花环、红围巾、毛线背心、雨靴 | 🦋 蝴蝶结发饰（新） |
| 🌙 深夜食堂（摆件） | 🍜 拉面、🍢 关东煮、🍙 饭团、🥟 饺子、🍡 团子、🍵 热茶 | 🏮 小灯笼摊（新） |

- 现有的其他装扮（墨镜、背带裤、领结、披风、礼帽、项链、翅膀）放进以后的系列；**已经买过、穿着的照旧保留**。
- 新装扮需要游戏本体认识它（挂在哪个部位、长什么样）。所以新装扮跟着游戏更新加，扩展只决定「从哪个盒子里出」。

## 4. 抽的规矩

- 每个系列单独买、单独算概率和保底。
- 一次抽 1 个，或者 10 连（便宜一点）。
- 普通款每个概率一样；隐藏款概率很低，但有**保底**：这个系列连续抽 N 次没出隐藏款，下一次必出；第 M 次起概率每次往上加（软保底）。数字见确认单。
- 重复的东西不会白抽：变成这个系列的**碎片**，攒够了换这个系列里任意一个没有的（隐藏款贵一些）。

## 5. 界面（扩展自己的 App「盲盒」🎁）

```
┌ 🎁 盲盒 ─────────────────────────┐
│ [开盒] [衣柜] [展示柜]             │  ← 三个页签
│                                    │
│  🌾 农场好朋友        3/7 · 碎片 4  │
│  ┌────┐  每个 300 🪙                │
│  │ 📦 │  [抽 1 个] [10 连 2700]     │
│  └────┘  再抽 23 次必出隐藏款       │
│  🌙 深夜食堂 ……                    │
└────────────────────────────────────┘
```

- **开盒**：盒子先摇两下、打开、东西弹出来，撒一点彩纸（canvas-confetti，ISC 许可）。10 连一次摆出 10 个，新的标「NEW」。
- **衣柜**：按部位列出有的装扮，点一下穿上 / 脱下（以后商店不再卖装扮）。
- **展示柜**：每个系列一排格子，没抽到的是剪影，集齐的系列标 🏅。
- 碎片兑换在开盒页每个系列下面：「用 10 碎片换一个」。

## 6. 存档和代码

- 扩展自己的数据（`state.extData.blindbox`）：每个系列抽了几次、离保底还差几次、碎片、摆件收集。
- 装扮的「拥有 / 穿着」仍然记在猪身上（和以前一样），扩展通过游戏给的口子 `api.own(key)` 发装扮。这个口子要随游戏一起更新，所以**盲盒要求游戏 ≥ v0.31.0**。
- 删除盲盒：清掉它的数据（摆件、碎片、保底计数）；**已经得到的装扮留在猪身上**（装扮属于猪，不属于盲盒）——见确认单问题。

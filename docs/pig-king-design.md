## 原有生命周期

原有按年龄派生的形态链保持不变。data/life.js 与 core/clock.js 决定：
纸盒 → 小猪 → 青年猪 → 成年猪 → 老年猪；死亡后为墓碑，之后可出现灵魂。
默认 timeScale=1，老年阶段从第 6 个猪月（180 个猪日）开始，寿命为 8 个猪月。
等级另由 XP 决定，不是分支形态。现有王冠是可以购买的装扮，不能代表加冕。

## 已确认的进化规则

沿用原有年龄阶段、寿命、学习、工作、属性增长与继承规则，只新增可选的猪猪王形态。

```text
纸盒 → 小猪 → 青年猪 → 成年猪 → 普通老年猪
                       └─ 主动加冕 → 猪猪王（仍按原寿命衰老）
                                   ↑ 老年阶段仍可补条件并加冕
```

| 条件 | 确定规则 |
|---|---|
| 阶段 | 已进入原有成年或老年阶段，且仍存活 |
| 智力 | ≥20 |
| 魅力 | ≥20 |
| 武力 | ≥20 |
| 工作经历 | 本代完成打工≥10次 |
| 玩家选择 | 满足条件后由玩家主动点击“加冕” |

- 未达标时先成为普通老年猪，进入老年阶段后仍可继续补条件，之后再加冕。
- 不设首次进入老年阶段的一次性判定窗口。
- 达标只开放加冕选项，不自动替换形态；玩家可以一直保留普通老年猪。
- 学习经历体现在现有三维属性的培养中，不额外要求大学毕业、指定课程或等级。
- 本代打工只计算成功完成的工作，中途取消不计入，不继承上一代的次数。
- 不新增金币花费、健康满值或其他未确认的进化门槛。
- 原有王冠装扮仍是装扮，购买或穿戴它不能替代加冕。

## 实现与兼容

条件读取现有traits与本代stats.jobs，沿用原有生命周期判断。
特殊形态单独持久化：年龄 stage 仍为 middle/elder，finalForm 为 king，年龄轴不变。
旧存档默认普通形态，未知值安全回退，不能自动替玩家加冕；存档版本升为 8，并补迁移与测试。

自动验收覆盖：三维19/20边界、打工9/10次、青年阶段不可加冕、成年阶段即可加冕、老年阶段补齐条件、
达标后不点击仍为老年猪、重复点击幂等、取消工作不计数、旧存档迁移与本代计数。
复活保留加冕选择；新一代重置形态与工作计数，原有三维和学习继承不变。王形态暂时隐藏头部与背部的装扮叠层，拥有/穿戴记录不变，避免重复王冠与披风。

本设计不增加收益加成，也不修改原有玩法数值。

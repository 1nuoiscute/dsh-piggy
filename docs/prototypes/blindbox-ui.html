盲盒新样子（原型）

按你说的改了四处，右边是和游戏里一样大小的面板，能点：

  • 风格跟猪猪面板统一：奶油底、圆角卡片、青绿按钮，不再用深色。
  • 摆件做成闪卡 + 立体小娃娃：卡框是星级颜色（灰 3★、紫 4★、金 5★、橙 6★），卡面有彩虹闪光，鼠标移上去卡片会跟着倾斜、闪光流动，娃娃从卡面里凸出来带阴影。
  • 开盒：礼物盒摇两下 → 盒缝透出星级颜色的光（5★、6★ 多一道光柱）→ 闪卡翻过来；十连两行小盒子逐个翻成闪卡，可跳过；6★ 撒彩纸。
  • 展示柜挪进「图鉴」：图鉴里多一个「摆件」分区，点进去是闪卡墙，点一张看大图、潜能和介绍。盲盒自己只剩「寻访」一页。
  • 凭证商店并进「商店」：商店里多一排「盲盒」货架，用资质凭证买，不再单独做一个商店。

顶上三个按钮切换看：盲盒（寻访）、图鉴·摆件、商店·盲盒货架。抽卡是假的随机，只为看样子。

# dsh-plugin-piggy

This is the `dsh-plugin-*` discovery alias for [dsh-piggy](https://github.com/CLICGGER-TYPES/dsh-piggy), a pig that lives in DeepSeek Harness and grows as you work. It installs the original `dsh-piggy` package as a dependency and loads its DSH bundle. The game, artwork, saves, and updates belong to the original project.

```sh
dsh plugin --profile web add dsh-plugin-piggy
```

Restart DSH and refresh the page. Install **either** `dsh-plugin-piggy` **or** `dsh-piggy` in one profile; both load the same pig. See the [project README](https://github.com/CLICGGER-TYPES/dsh-piggy#readme) for gameplay, screenshots, desktop downloads, and source code.
